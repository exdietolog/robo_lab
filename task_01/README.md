# robo_lab

Лабораторные работы по робототехнике на Godot.

## Лабораторная №1 — кинематика манипулятора

Проект: [`software_0b00/`](software_0b00/). Методичка: [`Лаб_раб_1.pdf`](Лаб_раб_1.pdf). Общие материалы курса: [`general.pdf`](general.pdf).

Для этого проекта нужны Godot **4.7.2 с поддержкой .NET** и **.NET 8 SDK**. Импортируйте `software_0b00/project.godot`. Чтобы запустить демонстрацию, нажмите **F5**. Чтобы запустить четырёхосевой манипулятор, откройте `TaskMain.tscn` и нажмите **F6**. Подробнее — в [README проекта](software_0b00/README.md).
