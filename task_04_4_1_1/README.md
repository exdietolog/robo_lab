## Лабораторная №4 — управление манипулятором асинхронными функциями (исходная версия, Godot 4.1.1)

Проект: [`software_0b11/`](software_0b11/). Методичка: [`Лаб_раб_4.pdf`](Лаб_раб_4.pdf) (исходная редакция).

Это шаблон лабораторной в исходном виде ([red-hara/software-0b11](https://github.com/red-hara/software-0b11)): Godot **4.1.1 с поддержкой .NET (Mono)**, `Godot.NET.Sdk/4.1.1`, `net6.0`. Задания не выполнены, в `Prefab/TaskController.cs` только демонстрационная программа. Нужен .NET 6 SDK (поддержка .NET 6 закончилась в ноябре 2024 г.; собрать проект можно и более новым SDK, но запускать его нужно в Godot 4.1.x).

Версия под Godot 4.7.2 / .NET 8 с поправленной методичкой — [`task_04_4_7_2`](../task_04_4_7_2/). Если проект из этой папки открыть в Godot 4.7.2, редактор предложит обновить его: результат будет почти таким же, как в `task_04_4_7_2`.
