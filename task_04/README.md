# Лабораторная №4 — Управление манипулятором асинхронными функциями (Godot 4.7.2)

Проект: [`software_0b11/`](software_0b11/) · Методичка: [`Лаб_раб_4.pdf`](Лаб_раб_4.pdf) · Общие материалы курса: [`general.pdf`](../general.pdf) · Описание всех лабораторных: [README](../README.md) ([English](../README.en.md))

Нужны **Godot 4.7.2 .NET** и **.NET SDK 8.0 или новее (подходит 10.0)**. В менеджере проектов нажмите **Import**, выберите `project.godot`, оставьте флажок **Edit Now** и нажмите **Import** (`software_0b11/project.godot`). Сборка — кнопка **Build Project** (молоток справа вверху) или **Alt+B**; **F5** запускает `main.tscn`.

Это чистый шаблон без решений.

- **Цель:** писать программу робота как обычный код с `await`, циклами и условиями, а не как заранее заполненную очередь команд.
- **Что есть в шаблоне:** готовые команды `Joint4` / `Linear4` / `WaitFor`, захват `Gripper`, два подающих конвейера `BoxSource` / `BoxSource2` (выдают коробку раз в 15 и 20 с) и демонстрационная функция `Run` в `Prefab/TaskController.cs`: робот берёт две коробки и ставит их стопкой.
- **Задание 1.** Переписать `Run` под задание преподавателя — уложить стопку коробок последовательным кодом (`PickBox` / `PlaceBox`).
- **Задание 2.** Повторяющиеся действия объединить в цикл.
- **Задание 3.** В цикле брать первую готовую коробку с любого конвейера: `await WaitFor(() => boxSource.BoxIsReady || boxSource2.BoxIsReady);`
- Ожидание коробок занимает много времени; ускорить симуляцию можно запуском `godot --path task_04/software_0b11 --time-scale 4`.

Та же лабораторная для Godot 4.1.1 — [`godot-4.1.1/task_04`](https://github.com/exdietolog/robo_lab/tree/godot-4.1.1/task_04).
