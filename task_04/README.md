# robo_lab

## Лабораторная №4 — управление манипулятором асинхронными функциями

Проект: [`software_0b11/`](software_0b11/). Методичка: [`Лаб_раб_4.pdf`](Лаб_раб_4.pdf) (поправлена под Godot 4.7.2, см. [README репозитория](../README.md)).

Это исходный шаблон лабораторной, переведённый с Godot 4.1 / .NET 6 на Godot **4.7.2 с поддержкой .NET** и **.NET 8 SDK** (подходит и более новый SDK, например .NET 10). Задания не выполнены: функция `Run` в `Prefab/TaskController.cs` содержит только демонстрационную программу шаблона.

Импортируйте `software_0b11/project.godot` и нажмите **F5**. В демонстрации робот берёт по коробке из двух источников (`BoxSource` выдаёт коробку через 15 с, `BoxSource2` — через 20 с) и ставит их стопкой в точку (1, −2, 0). Чтобы не ждать, запустите `godot --path software_0b11 --time-scale 4`.
