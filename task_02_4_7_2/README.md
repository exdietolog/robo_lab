## Запуск

1. Установите **Godot 4.7.2 с поддержкой .NET (Mono)** и **.NET 8 SDK**.
2. В менеджере проектов Godot нажмите **Import**, выберите `task_02_4_7_2/software_0b01/project.godot`, оставьте флажок **Edit Now** и подтвердите импорт.
3. Нажмите **F5**: Godot соберёт C# и откроет `Main.tscn`, демонстрацию команд `Joint3` и `Linear3` для трёхосевого робота. При первой сборке могут загружаться пакеты с NuGet.org.

Методичка сохранена без изменений: для запуска используйте шаги выше, если названия кнопок в PDF отличаются.

Это исходный шаблон без решений. По методичке нужно задать свою последовательность движений в `Prefab/Sample/SampleController.cs`, перенести кинематику из ЛР 1 в `Prefab/Task/TaskRobot.cs` и реализовать команды `Joint4` и `Linear4` для четырёхосевого манипулятора.
