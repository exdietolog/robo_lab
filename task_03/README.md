# robo_lab

## Лабораторная №3 — локальные системы координат инструмента и базы

Проект: [`software_0b10/`](software_0b10/). Методичка: [`Лаб_раб_3.pdf`](Лаб_раб_3.pdf) (поправлена под Godot 4.7.2, см. [README репозитория](../README.md)).

Это исходный шаблон лабораторной, переведённый с Godot 4.1 / .NET 6 на Godot **4.7.2 с поддержкой .NET** и **.NET 8 SDK** (подходит и более новый SDK, например .NET 10). Задания не выполнены: в `Code/Command/Joint4.cs` и `Code/Command/Linear4.cs` оставлены заготовки с комментариями `(1.x)` / `(2.x)`, код для второго задания в `Prefab/Task/TaskController.cs` закомментирован.

Импортируйте `software_0b10/project.godot` и нажмите **F5**. Пока заготовки не заполнены, робот стоит на месте; при сборке будут два предупреждения о неиспользуемом поле `progress` — они исчезнут после выполнения заданий 1–2.
