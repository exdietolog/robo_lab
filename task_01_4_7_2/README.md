# robo_lab

Лабораторные работы по робототехнике на Godot.

## Лабораторная №1 — кинематика манипулятора

Проект: [`software_0b00/`](software_0b00/). Методичка: [`Лаб_раб_1.pdf`](Лаб_раб_1.pdf). Общие материалы курса: [`general.pdf`](general.pdf).

Для этого проекта нужны **Godot 4.7.2 с поддержкой .NET (Mono)** и **.NET 8 SDK**. В менеджере проектов нажмите **Import**, выберите `task_01_4_7_2/software_0b00/project.godot`, оставьте флажок **Edit Now** и подтвердите импорт. Нажмите **F5**, чтобы собрать C# и запустить демонстрацию трёхосевого робота (`Main.tscn`). При первой сборке могут загружаться пакеты с NuGet.org.

Шаблон перенесён из `task_01_4_1_1/` без изменений в коде задания. Методички остались прежними.

Четырёхосевой манипулятор, его сцены и решения кинематики в шаблоне отсутствуют. Детали для сборки лежат в `Resources/Models/Task/`. Создайте сцены и скрипты в `Prefab/Task/` по методичке.
